## 问题与可检验预测

在岸基多源轨的 MTAD 位置回放中，当前格与去重历史对同一批轨给出竞争配对时，只降低该分量所涉轨的历史权重，能否纠正三格历史延续的错配，同时保住无冲突时的真替换。v1.5 的 4409 在固定槽下有 540 个端点秒呈当前格整组偏真、三格偏假，另有 320 个端点秒局部偏真但原目标两边交换增成本。3062 仅当前格经常换成另一假边。4827、4979 的去重臂完全保住原真替换。竞争解释包括普遍缩短记忆的作用、求解器搜索局限、局部更新不足以及单源输出缩短长链。主要预期是选择性使用旧格优于同强度全局衰减，体现在 4409 换真与全稀疏场长错链，而 3062 可作为换假的反例。近期 TSA-cTFER、MH-T2TA、Nguyen 和 Draves 的先例由候选评审定位。当前检验只支持该机制在共同比较条件下的价值。

## 冻结规则与五臂

固定原 v1.5 的 Level1 原 28 个 T_core 场、28 个共享 A 组件、活动片段与完整跨源候选、全窗排序和并列保护、KF 前缀、20 秒发布、Fréchet 掩码求解器的搜索路径与参数（截断 4 km、人口罚 4 km/√2、种子 20、两轮）、单源输出和 ID 读出。标签及参考只在全部预测冻盘后用于评分。量测侧只读已到位置和时间，遵循原片段等同性与速航遮蔽。T_test 封存。A 原三格、B 仅当前格、C 报文去重逐版复算 v1.5。D 和 E 都以 C 的去重格为底座，各轨对其格龄 k 使用相同的衰减函数，权重 2 的负 k 次方。当前格、前一格、前两格的权重为 1、1/2、1/4。

- **D 统一衰减**对所有轨启用衰减。**E 冲突衰减**对触发分量中的轨启用同一衰减，其余轨各格权重为 1。
- 决策时在共同的有序去重轨上分别算两个诊断匹配。候选距离为当前格或去重共同格上的截断平方距离均值，以截断平方归一至 [0,1]，两边空配代价各 0.5，沿用部分指派及并列规则。取两个诊断匹配的对称差，在其交替分量中，至少有一个端点出现不同的两个实际搭档，且该分量至少有一条轨的最近原生报文在上一发布点之后到达，触发该分量权重。首个发布点缺上一发布参照，沿用全权重。诊断配对只决定权重，不改候选、槽或发布。标签、选定场号、旧全局 ID 和旧发布真伪均不输入判据。记录触发帧、分量、端点数和计算成本。
- 掩码内一条源轨的残差按其当前权重在与中心的共同格上分别归一，人口分母和基数罚固定。每个格的中心最小化两侧按源人口和归一化时间权重加权的截断损失。成对搜索代理对称取两条源轨各自的归一距离均值，固定中心指派使用待评源轨自己的权重。单格与单位权重还原原行为。D/E 均在最终槽和相同人口分母下按原三格的当前点融合公式发布位置，以隔离相同组时位置变化直接触发 ID 换手的因素。终端 Fréchet 搜索次数、种子、候选合格性及发布规则各臂一致。影子匹配成本计入 E。
- A/B/C 与 v1.5 的逐版记录除耗时外逐字段相同，全部五臂的批时刻、活跃成员及最近报告时刻一致。焦点使用原 v1.2 状态与重现的 v1.5 三格所定义的共同争议区间，以相同失鲜切点累计，保留端点秒与配对秒两个单位。现有 v1.5 固定原槽数、重拟变动槽的受限价差证据用于识别搜索替代解释，不能推断全局最优。

## 终点、样本与止损

主比较 E 对 C 和 E 对 D。主终点是 24 个预先定义稀疏场持续严格超过 60 秒的假边累计配对秒。报告绝对差、逐共享 A 组件差、场级方向和逐一剔除组件的合计范围，另列剔除 4827。4409 与 3062 用同一争议区间分解同假、换真、换另一假边、单源和失鲜。4827 与 4979 对原三格换真的共同区间核同真搭档保全率。次要终点为全体和稀疏正确首报及按事件保留/流失/增加、从未见真对侧的误接、总错漏配、唯一纯 ID 秒和换手、确认 20/60/120 秒及最终覆盖、P50/P95、双方确认事件的成对先后和服务代价。成功者延迟只代表有确认者。互相重叠的发布格不作独立样本。

开发晋级须同时满足：E 的稀疏长错链秒严格小于 C 和 D，剔除 4827 后仍同向；4409 真替换端点秒多于 C，且 3062 的另一假边端点秒不超过 C；4827 和 4979 各保住原真搭档 ≥95%；稀疏正确首报覆盖和 20/60/120 秒及最终确认覆盖均不低于 C，稀疏错配、漏配、换手均不高于 C，唯一纯 ID 覆盖不低于 C。首报按事件保全与确认尾部作为解释性护栏。只降低错链但转向其他假边或减少发布视为指标取舍。同强度统一衰减持平或占优时结束本配方的开发晋级，保留焦点证据与失败报告。近邻先例和焦点来源限制了结论范围，即使全过也只支持原 28 场上的开发结果。

复用原冻结的三卷数据、v1.2/v1.5 公开配置和本地私有输出。一次本地 CPU 回放，30 分钟墙时上限，先完成软件校验并冻结代码。越界读取、对照不一致、非有限代价、重复成员或超时则保全已完成产物。输出目录新建，逐报成员和争议时标保留在本地，仅发布场级汇总和焦点积分。结束后 Record → Squeeze → Mode C。
