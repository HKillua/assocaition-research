# 接回当批的全局互斥、空配与外围代价

2026-11-14。检索 2025–2026 年纯传感器的 *global association*, *partial assignment*, *ranked assignment*, *multi-radar track association* 和 *joint probabilistic data association*。以下记录原文机制、消融范围及可迁移条件。未将其它数据的论文数值计作 MTAD 验证。

| 原文与覆盖 | 直接证据和作者主张 | MTAD 迁移判断及未知 |
|---|---|---|
| E-ON305，Tao 等，Applied Sciences 2026，§3.4 式 22–24、§4 表 1–2。 [原文](https://www.mdpi.com/2076-3417/16/7/3159) | 在参考雷达和其他雷达间构造位置协方差、Doppler、SNR 等代价，分别筛选存在概率和距离，用 Murty 配合二分指派排多种互斥匹配。原文明确总代价较小并不推出每个航迹匹配正确。表 2 同参数雷达仿真整体 OSPA 2.4705 米，GA-LMB 4.5217 米，PHD-AA 5.1392 米。 | 需核全局边集合而非局部某条边。仿真对比同时改变特征、标号及融合，不能将差异归给优化器；其多雷达方案本身按参考源配对。 |
| E-ON306，Wu、W. Chen、W. Chen，Sensors 2026 卷 26，§§4–6、图 9、表 2。 [原文](https://www.mdpi.com/1424-8220/26/1/49) | 用嵌入和聚类构造组级加权二分图，Kuhn–Munkres 选互斥匹配，再做组内互支持验证。近目标间距与噪声相当的仿真中报告 92.6%，JPDA 约 20%。表 2 主要消融聚类、特征和验证模块。其 TAA 以融合点距真值的邻近性计分。 | 可以借鉴先匹配后验同组配对和受牵连边。论文没有固定同一候选图仅换求解器的实验，不能用 TAA 代替 MTAD 持续身份。 |
| E-ON307，Shi、Wang、Wei、Liang，Sensors 2026，§4.4、§§5.1、5.3 表 3。 [原文](https://www.mdpi.com/1424-8220/26/7/2255) | 实测内河 AIS／雷达 2024-09-06 至 10-23 的 468 艘船资料，经清理及平衡后保留 30,000 个时刻，时间对齐、预测与距离 Kuhn–Munkres 联用。当候选数不同时增零权虚拟雷达，空配为不对称约定。作者报告低密度 F1 97.0%、高密度 81.9%；高密度准确率 80.1%，NN 为 58.7%，PF 为 76.2%。 | 近邻与整组必须同算，空配的含义依输入和代价。MTAD 沿原双侧空配、不改图；原文插值、时间处理和 AIS 标识并非本轮可用信息。 |
| E-ON308，Khosravi、Ventura、Basiri，IEEE ICMRE 2026，§III-C、§V-B 表 II。 [作者全文](https://arxiv.org/html/2603.11586v1) · [DOI](https://doi.org/10.1109/ICMRE69538.2026.11533899) | 同 LiDAR 检测、门和 IMM 下对照 Hungarian 与 JPDA；三种有 ID 切换的仿真场景平均切换 4.4→1.6，MOTA 0.573→0.570。真实数据仅用于检测验证。 | 同输入隔离指派，且把局部或帧内正确、整体准确率和持续 ID 分开。原文是软后验对硬指派，非本轮坐标置换。 |
| E-ON309，Bai、Wang、Pan、Yun、Lan，IEEE TAES 2025，作者稿 §§III–IV、表 III。 [作者全文](https://arxiv.org/html/2310.12407) · [DOI](https://doi.org/10.1109/TAES.2024.3491936) | 雷达空间观测的因子图关联与距离–多普勒类别信息联合推断。IPIX 真实海杂波加仿真目标，表 III 对比同系消息传递：AMOT −0.21→0.27、MOSPA 8.48→5.18，IDS 3.93→4.10。 | 关联置信度与目标数量/位置改善不能代替身份保护。MTAD 没有该波形特征，也不改变本轮候选或用类别模型推断。 |

补充定向复核 Kropfreiter、Williams、Meyer，IEEE TSP 2026，§VII-A 式 55–56、§VIII [作者原文](https://arxiv.org/html/2504.16814v1) · [DOI](https://doi.org/10.1109/TSP.2026.3659742)。目标到量测单元的全局关联边缘概率在联合后验近似前求出。500 次仿真将 GOSPA 拆为定位、漏目标和假目标，近邻交会的漏目标部分有所改善。其输入为原始雷达单元强度，软边缘概率和一个固定图的硬指派可提供不同证据。

补充定向复核原 S-ON60／E-ON137，Draves 等 MFI 2026 [作者稿](https://arxiv.org/html/2610.20290v1)，互斥本地航迹组合维护跨事件假设，星座模拟比较当批 GNN。其更长跨时段证据、分支保留和网络融合不属于本轮单批干预。当前检验保持原 C28 求解器，独立改变同一触发位置影响的边代价。必须把任何焦点边仍接回、两边完整换配、接外围边或空配，以及受影响的正确身份分开。
