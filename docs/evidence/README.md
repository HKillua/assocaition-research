# 在线实验归档证据

这里保存 2026 年 11 月 10–14 日 MTAD 在线观测的指标、汇总和核验材料。每份文件的归档路径、版本类型和筛除项数见[清单](catalog.tsv)。实验设计与条件见[提案](../proposals/README.md)，真实执行、异常和取舍见[报告](../reports/README.md)，机制证据回流见[在线 Mode C](../surveys/2026-10-26_mtad_actual_use/online_causal_replay_mode_c_20261111.md)。

清单中的 JSON 原件有 38 份，汇总副本有 46 份。汇总副本保留原指标、计数和验证字段，清理逐报与单例结构、坐标与位移向量、细粒度时间戳及机器路径。科学解读以原执行与对应报告为准。

逐报结果、冻结图与状态、训练权重和原始运行日志由本地研究资料库保管。拥有对应实验资料时，证据根目录下可按 `20261111_online_mtad` 至 `20261114_online_mtad` 的日期目录及报告给出的任务名定位原件。2026-11-10 工程回放的逐秒原件也保存在本地，仓库提供[计时与计数汇总](20261110_online_replay/summary.json)。
