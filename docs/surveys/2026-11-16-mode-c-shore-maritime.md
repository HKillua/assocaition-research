# 岸基海上多传感器态势感知 · Mode C 证据矩阵

2026-11-16。覆盖固定岸站或岸上处理的海上、港口与临海航道。同一水域可由多源共见，量测、收报与发布可以错时。MTAD 是匿名航迹级开发语境，真实岸基观测和有出处的仿真用于确认研究设置及边界。对 100 篇固定文献先逐篇分析，再围绕三个问题综合。一，什么才算可用且独立的证据。二，首报、空配与接续怎样体现到同一发布协议。三，评价何时能反映在线位置和身份质量。

- 上游 `ANALYSIS_PACKAGE` 为 `AP-ONLINE-SHORE-DETAILED-20261116`，S01–S100 沿用[冻结书目](2026-11-16-shore-maritime-reading.md#100-篇核读记录)的顺序。研究设计、操作／公式、主张、结果、局限、复现与待核均见逐篇条目。下方 E 表定位被用于建立核心 F 的资料；其余读本用于比较研究接口、任务边界和共享数据。

## F · 已观察现象

| ID | 观测及边界 | 证据 |
|---|---|---|
| F01 | 真实岸站可以在收报时配对。M2 的发表速度统计却只保留已配长轨，排首分钟与急转；苏格兰视觉调查揭示不少船根本没有 AIS 反映。检测／配对／参考是三个入口。 | DE，原条件下强。 E01–E03 |
| F02 | HAXR 各站 AIS 是相同广播的分站视图，邻接滑动旋转可重用回波。MTDSP 两个抽样包的 13 个 AIS 文件有 12 个完全相同；PoLaRIS 一部分跨模态标注来自投影。 | DE，高，数据语义；待核全样本。 E04–E06 |
| F03 | 真船 AIS 相对 RTK 出现 16–19.5 秒最佳移时，最大沿航迹误差 117.1 米；固定 LiDAR 比对又受船壳与天线点的区别影响。受控多目标仿真显示未知时偏可让融合劣于单源。 | DE，中高，现场误差和模拟干预各自成立。 E07 |
| F04 | 邻轨能帮助密集海事关联。GMvA 高密度 .8673 降到删十条记录后的 .4545；另一岸站离线 GCN 加线性优于单线性，纯图显著较弱。 | DE，中，设置与分母不同。 E08–E09 |
| F05 | 有显式空配的整窗模型中，IAGM 同时去掉 dustbin 和相关损失时 PFA 7.25→14.38%；另一个 MTAD 外测方案提高精确性但召回低于最近邻。 | DE，原协议下强，迁移依据中等。 E10–E11 |
| F06 | 加长窗有时提高 AF1，有时过长反降。MH-T2TA 的 20→60 秒上升，HTG-TA 在 60 秒最佳，200 秒明显回落。TSA-cTFER 的跨源正确确认平均等待 246.95 秒。 | DE，中高，分享 MTAD；分别用各论文窗、分母和时间定义。 E12–E13 |
| F07 | DPTF 重现后用新视频补证提高 FVessel 的平均帧正确率，却在一个视频反向；Draves 以场末最佳假设回看全历史，早期错误仍可传播。 | DE，中；支持区分在线首次和可改历史。 E15–E16 |
| F08 | 延长预测保留可使假轨存续更久。ESMaS 预测计数 4 的 IDF1 最优，继续延长后 IDF1 降与 FP 增；渤海实测断片的全局求解仍会错接，长断口也可使真边在粗门被删。 | DE，中高，单源现场。 E17 |
| F09 | 加源并非总能增益。汉堡第三部岸站的反射生成短假轨并使形状估计变差，固定近岸相机和 LiDAR 的多传感也有退化反例。 | DE，中，物理场景相异，未合并效应。 E18–E19 |
| F10 | 关联与状态质量可能反向。PTFM 在已配真轨降低位置 MAE，同时速度与航向 MAE 上升；近水面 LiDAR 在中距少量可评帧上的位置误差很小，但丢失率近八成。 | DE，原口径下强，针对全人口外推须复核。 E19–E20 |
| F11 | 论文协议与作者配置可能改变时间和难度。DeepSORVF 原文 15 次确认和 15 秒遗忘，固定代码两项都是 3。道路协同研究的传输负载改变了增加源的检测收益方向。 | DE，各设置内配置有直接核验。 E14、E21 |
| F12 | 现有仿真资产覆盖不同环节。Player 支持为同船分别生成各源报文，ASVSim 描述未模拟海杂波等项，Online EM 作者仿真则假定所有同步目标俱在。 | DE，资产前提有直接证据，部署表现待核。 E24–E26 |
